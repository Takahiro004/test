- `Assets/Script/Game/TwoPlayerShop2D.cs` が本体。シーン `SampleScene` で `DisplayTestSwitcher` と一緒に動いている
  - 1つのスクリプトを partial class で5つのファイルに分けている（Unity からは1つの部品）。本体 `.cs`（設定の欄・初期化・棚・移動・掴む/離す）／`.Clash.cs`（掴み合い）／`.Bag.cs`（レジ袋・金額・消す）／`.Sprites.cs`（図形の自動生成）／`.Input.cs`（入力）／`.ShopView.cs`（棚の画面の向き）
  - Inspector の欄の順番が変わらないように、public の設定はすべて本体 `TwoPlayerShop2D.cs` に置く
- 3画面: 画面1 = 1P / 画面2 = 商品棚 / 画面3 = 2P
- できていること:
  - 棚に商品6個を自動生成
  - コントローラーは最初に A を押した方が 1P、次が 2P（キーボード予備: 1P WASD+Space / 2P 矢印+Enter）
  - 棚で A → 商品とカーソルが自分の画面へ移る → 位置を決めて A → 重力で落ちて床に積もる → カーソルは棚へ戻る
  - **2画面化（リーダーが Unity で設定）**: カメラの Target Display を 画面1 = Display 1 / 画面2 = Display 2 / 画面3 = Display 3 にした
    - エディタではテストモード（1枚に3画面を並べる）。再生中に F1 で本番の分け方。Game ビューを増やして Display 2 にすると2枚目が見られる
    - ビルドした exe はモニターが複数あれば自動で本番の分け方になる
  - **棚の補充（2026-10-14 プログラマーの Claude が追加・Unity で動作確認済み）**: 商品を取ると、`Refill Delay`（1.5秒）後に同じ場所へ同じ商品が出る。Inspector の「棚の補充」で ON/OFF と秒数を変えられる
  - **自分の画面では横移動だけ（2026-10-14 プログラマーの Claude が追加・Unity で確認済み）**: 商品を持って自分の画面にいる間は左右にしか動かない。高さは Inspector の `Drop Height`（3.5）。上限なし（5 より大きいと画面の外から落ちる）。棚に戻ると上下左右に戻る
  - **床の高さ（2026-10-14 プログラマーの Claude が追加・Unity で確認済み）**: Inspector の「落下(物理)」→ `Floor Y`（-4.5）で 1P/2P 画面の床の高さを変えられる。再生中に変えてもすぐ床が動く
  - **レジ袋（2026-10-14 プログラマーの Claude が追加・Unity で確認済み・仮の仕様）**: 1P/2P 画面の床の上にレジ袋（白い U 字）を置いた。商品の中心が袋の内側に入った瞬間に「+¥金額」が浮かんで消え、袋の上の合計に足される。商品は袋の中に積み重なる
    - Inspector の「レジ袋」で 位置 `Bag X`・幅・高さ・ふちの太さ・色・商品ごとの金額 `Product Prices`（左上から 100/150/200/250/300/500）・表示時間を変えられる（再生中も反映）
    - 1回入ったら、あとで袋からこぼれても合計は減らない。床に落ちた商品は数えない
  - **袋の外に落ちた商品は消える（2026-10-14 プログラマーの Claude が追加・Unity で確認済み）**: 床に着いたら（袋からこぼれたものも）小さくなって消える。袋に入らずふちや他の商品の上で 0.5 秒止まったものも消える。Inspector の「レジ袋」→ `Remove Outside Bag`（ON/OFF）・`Remove After Stop Time`（秒）
  - **掴み合い（2026-10-14 プログラマーの Claude が追加・直し・引き分けのやり直しは未確認）**: チャージインパクト風
    - 棚で A を押すと、商品はすぐ自分の画面へ移る（待ち時間なし）
    - 取られてから `Grab Window`（0.5秒）以内に、もう1人が同じ場所で A → 商品が棚に戻って掴み合い
    - 棚の画面の下にゲージ（1P 左・2P 右。外側が細く、真ん中の VS に向かって太くなる形）。0→最大→0 と往復し、A で止める
    - **2人とも A を押すまで終わらない**。最大に近い方が勝ち、商品は勝った人の画面へ。金色の範囲なら「パーフェクト！！」。**引き分け（表示の数字 0〜100 が同じ）なら「引き分け！ もう一回！」でゲージを戻してやり直し**
    - Inspector の「掴み合い」で 秒数・ゲージの速さ・パーフェクトの範囲・表示時間・ゲージの高さを変えられる。`Grab Window` を 0 にすると掴み合いなし
  - **棚の画面（画面2）の向き（2026-10-14 プログラマーの Claude が追加・未確認）**: 本番は縦型モニター、テストは横型モニターなので切り替えられるようにした
    - Inspector の「棚の画面(画面2)の向き」→ `Shop Orientation`: 横（今まで）／縦／縦(右回り)／縦(左回り)。再生中に変えてもすぐ反映
    - 縦: 横のモニターでは真ん中に縦長で出る（左右は黒）。本番の縦モニターでは画面いっぱい。Windows で画面の向きを「縦」にして使う場合はこれ
    - 縦(右回り・左回り): Windows は横のまま、モニターだけ90度回したとき用。逆さに見えたらもう一方を選ぶ
    - 縦のときの配置: 上の `Portrait Top Space`（2割）をタイマー用に空けて「TIMER」の目印、その下に棚を `Portrait Columns`（2列）x 3段。`Portrait View Width`（8）を小さくすると棚が大きく映る。比率は `Portrait Aspect`（9:16 = 0.5625、モニターが決まったら合わせる）
    - 掴み合いのゲージは、縦のとき画面の下に縮めて出す
  - **画像の欄（2026-10-14 プログラマーの Claude が追加・Unity で確認済み）**: 画像ができたら Inspector にドラッグするだけで差し替えられる
    - 「商品の画像」`Product Sprites`: 棚の左上から6つ。空の欄は四角・丸のまま。画像の商品は当たり判定が画像の形になる。大きさは `Product Image Size`（2）
    - 「レジ袋」`Bag Sprite`: 袋の幅・高さに引き伸ばして、商品より奥に表示。ふちは見えない壁になる
    - 画像は再生を始める前に入れる（再生中に入れても反映されない）
